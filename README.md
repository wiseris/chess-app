# Chess App

Сетевая шахматная игра

## Модули

- `server` — серверная часть
- `shared` — общие классы, модели, команды и др
- `client` — клиент на JavaFX

## Сетевое взаимодействие

1. Клиент → `ChessCommand` (в `Envelope`) → Сервер
2. Сервер десериализует через `ChessCommandFabric`
3. Выполняется логика, возвращается ответ
4. Клиенты получают `UpdateGameState`

### Основные команды

| Команда | Назначение |
|---------|------------|
| `ConnectServer` | Подключение к серверу |
| `CreateLobby` | Создание лобби |
| `JoinLobby` | Вход в лобби |
| `StartGame` | Запуск партии |
| `ActionCommand` | Ход фигурой |
| `UpdateGameState` | Синхронизация состояния |
| `UpdateMembers` | Обновление состава лобби |

### Основные сущности

| Класс | Описание |
|-------|----------|
| `GameData` | Состояние игры: игроки, фигуры, история |
| `FigureData` | Фигура: позиция, цвет, тип, валидация хода |
| `CellPosition` | Клетка доски, шахматная нотация |
| `HistoryData` | Запись хода (from/to, шах, мат, рокировка) |
| `LobbyData` | Лобби: хост, участники |
| `MemberData` | Игрок: id, имя, статус |

### Фигуры

`King`, `Queen`, `Rook`, `Bishop`, `Knight`, `Pawn` каждая реализует свою логику хода, проверку препятствий и шаха.

Особые ходы: рокировка, en passant, превращение пешки.
